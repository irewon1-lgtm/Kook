# KR4 APK → PC 기능·정보 대조표

**전체 완료 판정: 미완료. 공개 배포: NOT_DEPLOYED. Windows/LG 실물: NOT_RUN.**

Android 기준 커밋 `a1676eab7bfe6b0d3765e4340504f8ff2a2d2a3f`와 현재 PC 작업 파일을 대조했습니다. 버전 4.3.210의 APK 실기기 실행 검증은 별도이며 Gradle 기본 versionName만으로 출시 APK 신원을 단정하지 않습니다. PC 코드가 아직 main에 게시되지 않은 시점의 문서입니다. 코드 줄번호는 후속 수정으로 이동할 수 있습니다.

`PASS`는 근거 열에 적힌 범위의 실제 실행만 뜻합니다. `LOCAL_BROWSER`는 Linux Chromium의 로컬 컴포넌트 하네스이며 공개 사이트의 manifest/hash/IndexedDB 수신·배포 검증이 아닙니다. `ORIGINAL_KOTLIN_TEST`는 원본 Kotlin 함수와 기록된 입력의 검사입니다. `NOT_RUN`은 구현 연결이 있어도 해당 동작/값 실행 근거가 없음을 뜻하고, `FAIL`은 실제 정적 누락, `BLOCKED`는 확인된 외부 장애입니다. 자료의 결측·IR 미확보는 그 자체로 앱 기능 오류가 아닙니다. 백분율 점수·95점 등 전체 품질점수는 계산하지 않았습니다. 중첩/교차 기능이 있어 행수 비율은 기능 완성률이 아닙니다.

## 확인된 범위와 남은 경계

- 실제 가격은 2,649종목 중 2,636개 저장 관측자료와 13개 명시적 MISSING입니다. CACHE는 게시본의 저장 일봉이며 실시간 호가가 아닙니다.
- 원본 Kotlin exporter는 2,649종목·15순위 조합·20해석필드·14리포트필드·원본 재무/후보/분기를 보존합니다. 동일 입력 원본 검사와 화면 표시 검사를 구분했습니다.
- 실제 000020의 공시 원문 본문2건과 원래 날짜를 확인했고, 모든 분류가 정상이라는 표현을 쓰지 않습니다. IR/official 빈 배열은 MISSING입니다. 이전 공시 보존/새 뉴스 독립/실패 시각 구분은 명시적 controlled503 회귀와 실제 저장자료 표시 검증입니다.
- DART 새로운 접근은 동일 요청 Python/JVM HTTP503으로 BLOCKED입니다. 이미 확보된 접수번호·본문·공시일을 보존하되 새 수집으로 바꾸지 않습니다.
- 로컬 전체 App6개 사례 최초 실행은5PASS와 잘못된 selector1건으로 최종 재실행 중이었습니다. selector 실패를 제품 결함으로 단정하지 않습니다. 최신 전체 통합·공개사이트·실물 검증은 이 표의 컴포넌트 PASS로 대체할 수 없습니다. 이후 로컬 전체 App viewport매트릭스29개 PASS 로그를 확인했으며 공개 배포/실물 결과로 확대하지 않습니다.
- root 단위57개와 가격원본 비교229개 PASS가 전달되었고 oracle14개 PASS 로그를 포함했습니다. 아직 미수신인 마지막 전체 로그/전역 suite는 이 문서에서 전체 PASS로 승격하지 않았습니다.

## 승인된 화면 참조 사용 규칙

승인된 home/ranking/detail/chart 이미지의 네이비·파란 위계, 큰 한글, 넓은 여백, 비교 가능한 열 구성을 참고했습니다. 이미지의 회사명·가격·점수·순위·비율·뉴스·분기 숫자는 예시이며 실제값으로 복사하지 않습니다. 실제 UI는 원본 엔진/관측자료만 표시하고 원본에 없는 미래 분기·거래일·가격·공시·본문은 만들지 않습니다.

## PC와 Android의 의도적 차이

- 하단 모바일 메뉴·가로 swipe는 상단 desktop 메뉴·클릭/키보드 탭으로 대응합니다. 선택기는 항상 펼치고 문서 흐름에 두며 고정 overlay로 만들지 않습니다. 페이지당50/100개 탐색으로 전체2649행에 접근합니다.
- 관심종목과 글씨 크기는 이 브라우저 localStorage의 개인 설정이며 로그인/ChatGPT/다른컴퓨터와 공유하지 않습니다.
- APK 설치·강제업데이트 창은 웹 게시본 확인, 원본 커밋/소스, 새 자료 확인으로 대응합니다. native 설치 흐름은 웹에 넣지 않습니다.
- Android가 직접 수집한 LIVE와 웹이 검증된 게시본을 새로 받은 LIVE는 의미가 다릅니다. 가격은 서버가 관측·게시한 CACHE로 표시하고 원천일/확인일/시도일/마지막 거래일을 구분합니다. 브라우저 새로 확인은 DART를 새로 수집했다는 뜻이 아닙니다.
- 원래 보조 해석필드·리포트필드도 PC에서 전체 공개하며 긴 본문은 펼쳐 전문에 접근합니다. 영업이익 YoY/QoQ는 같은 CFS/OFS·정확 전년/전분기·양수 전기금액일 때만 단순 산술을 표시하고 원래 추세 판단을 바꾸지 않습니다.

## 중요 누락

감사 중 발견한 홈/순위 독립 펼침·inline4지표/Stage4/5, 홈 지표별 확보수/확보율·교육, 없는 종목 전용안내, 관심 picker 정렬/빈결과/바깥클릭은 root가 복원했고 코드를 재확인했습니다. 최신 동작 증거를 받기 전에는 NOT_RUN으로 남깁니다. 원본 순위설명 전체 접근은 별도 보완 필요이며 차트 탭 왕복시 선택상태 유지도 실제 검증이 필요합니다. 새 storage event 동기화도 확인했으나 원본 Android 필수동작과 구분합니다.
